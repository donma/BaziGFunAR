# BaziGFun AR 八宅實景

**站在八宅羅盤的正中央。**
打開相機，你會像置身一座發光的霓虹羅盤：腳下與四周是青藍色的八方位盤，一圈圈寫著卦名、星名、地支和二十四山，告訴你每個方向對你的命卦是吉還是凶。轉動手機，盤面會跟著真實方位轉。

- 不用網路也能用（第一次開啟後）
- 所有資料只存在你的手機，不會上傳
- 可以安裝到手機主畫面，像一般 App 使用

👉 線上試用：https://donma.github.io/BaziGFunAR/

> ⚠️ 八宅風水是傳統文化參考，不是科學驗證。盤面是「以你站的位置為圓心」的方位示意，不會偵測家具或房間，也不等於整間房子的正式判定。

---

## 3 步開始使用

1. **建立人物**：輸入名字、國曆生日、性別（出生時間可不填），App 會自動算出命卦。
2. **按「進入 AR」**：允許相機，以及「動作與方向」感測（iPhone 一定要點允許）。
3. **拿起手機環顧四周**：往下看是地板上的八宅盤，平視可以看到地平線上的方位標記。

## 畫面怎麼看

| 你看到的 | 代表什麼 |
|---|---|
| 腳下 8 塊發光的藍色玻璃扇形 | 8 個方位。**亮藍色是吉方；靛紫色並帶一點暖橘邊光的是凶方**，扇區中間大字是星名（例如伏位、生氣、五鬼），旁邊標了「吉」或「凶」 |
| 正下方圓心的大八卦 | 填滿圓心的發光八卦：中央太極、外圍一圈卦名、八個卦象、外緣一圈二十四山。往下看時最明顯 |
| 目前面向的那一塊會亮起 | 你現在朝向哪個方位 |
| 一圈圈發光的楷體字（由內往外） | 卦名 → 五行與洛書數（如「金六」）→ 方位與吉凶 → **星名** → 星意（如「利穩定休息」）→ 十二地支 → 二十四山 → 二十四節氣（朝遠方看時可見）。這些字固定在真實方位上，不會亂轉 |
| 八角形切面線與同心光環 | 像寶石切面的地板，並標出度數刻度 |
| 發亮的小三角標「北」 | 正北方 |
| 地平線上的 8 道光柱 | 平視時也能知道各方位的吉凶，不用一直低頭 |
| 緩緩掃過的光束、從中心擴散的光環、流動的光點與升起的光塵 | 純裝飾的特效，營造沉浸感；手機跑不動或系統設定「減少動態效果」時會自動變成靜態 |
| 頂部的數字，例如「315° 西北」 | 手機現在朝向的角度與方位 |

**想看詳細說明**：點一下任何一塊扇區，底部會滑出該方位的解讀（吉凶意思、方位依據、佈局參考）。上滑可展開，下滑或按返回即可關閉。平常畫面上不會有任何卡片擋住景色。

**拍照**：按下中間的快門，一次會存兩張照片，放在同一筆紀錄裡：
- 原始實景照（乾淨，沒有任何疊圖）
- AR 合成照（有八宅盤，並附上人物、方位、吉凶資訊）

預設還會**自動讓瀏覽器下載那張 AR 合成照**（檔名像 `bazigfun-ar-20261127-171254.jpg`）。不想要的話，到「設定 → 拍照」關掉。原始實景照只存在「紀錄」裡，可在紀錄中分享或匯出。iPhone 以「加入主畫面」使用時，下載行為依 iOS 而定；若沒有看到檔案，請到「紀錄」按「分享」→ 儲存影像。

## 常見問題

**盤面的方位好像不準？**
手機的指南針很容易被金屬、電器、手機殼的磁鐵干擾。請把手機對準一個你確定的方向（例如知道哪邊是北），按上方的「校正」，選擇對應的方位即可。

**畫面變暗、出現「需校正」？**
表示手機給的方位資料不夠可靠，為了不顯示錯誤資訊，盤面會自動調暗。校正後就會恢復。

**為什麼一次只看到一個扇區？**
直立手機的視野比較窄（約 33 度），一個扇區是 45 度。轉動手機環顧即可。

**盤面和實際地板對不齊？**
地板是「假設手機離地 1.4 公尺」畫出來的虛擬平面，App 並沒有偵測真實地板，所以只是營造沉浸感。若覺得透視不自然，可以到「設定 → 畫面視角」微調。

**「朝向參考」和「住宅中心方位」差在哪？**
- 一般情況只標「目前位置方位（朝向參考）」。
- 如果你在設定中勾選「我站在住宅中心」，而且感測良好，才會標「住宅中心方位」。
- 即使如此，也不等於專業的整間房子判定。

**會不會上傳我的照片或生日？**
不會。沒有帳號、沒有伺服器，資料都在你手機的瀏覽器裡。清除網站資料會讓紀錄消失，建議定期在「紀錄」匯出備份。

**拒絕了相機或方向感測會怎樣？**
AR 會暫停並說明原因，同時提供重新授權的按鈕。人物管理、命卦方位、拍照紀錄、手動方位工具等功能仍可使用。

## 目前的限制（誠實說明）

- 還沒有在真實 iPhone / Android 手機上做完整量測，所以**不保證精準度、不承諾支援哪些機型**。
- 方位完全靠手機指南針，室內可能有偏差，請善用「校正」。
- 不辨識家具、門窗；吉凶只由「你的命卦」與「面向的方位」決定。
- 不提供舊版 BaziGFun 的人物匯入、雲端同步、帳號。
- 不支援真北自動換算；若要真北，需自行在設定輸入當地磁偏角。

## 給開發者

### 常用指令

```bash
npm install
npm test               # 單元測試（95 項）
npm run dev            # http://localhost:5173/BaziGFunAR/
npm run build          # 型別檢查＋建置到 dist/
npm run preview        # 預覽建置結果（http://localhost:4173/BaziGFunAR/）
npm run smoke          # 真瀏覽器端到端測試（需先 preview）
npm run icons          # 重新產生 PWA 圖示
```

需要 Node.js 20 以上。相機與方向感測需要 HTTPS 或 localhost。

### 部署到 GitHub Pages

`dist/` 在本機編譯後一起 commit，GitHub Actions 只負責把現成的 `dist/` 發佈，**不會安裝套件或編譯**。改程式後請依序：

```bash
npm test
npm run build
git add -A && git commit -m "..." && git push
```

忘了 `npm run build` 的話，網站會是舊版。

### 程式結構

```
src/domain/    命理核心：立春換年、命卦、八宅吉凶、方位計算（從原版 BaziGFun 逐字移植）
src/sensors/   方向感測：權限、濾波、校正、朝天時凍結（同樣移植自原版）
src/camera/    相機啟停與畫面裁切（移植自原版）
src/vr/        偽 VR 盤面：3D 姿態與投影（math）、繪製（render）、場景控制（scene）、可信度標示（status）
src/capture/   拍照：原始照＋AR 合成照、紀錄組裝
src/storage/   本機儲存：人物與設定存 localStorage，照片與紀錄存 IndexedDB
src/export/    匯出 JSON / 照片 / ZIP
src/app/       手機介面：主畫面、底部資訊卡、設定、手動方位工具
docs/          稽核對照、決策記錄、驗收與限制
```

### 技術重點（簡述）

- **不用 WebGL**：用 Canvas 2D 自己做透視投影，再用加法混色做出霓虹發光。每個字只在第一次使用時烘焙成發光貼圖並快取，之後每幀只是貼圖，避免上百次模糊運算讓手機發燙。另外用「縮小再放大疊回」做出低成本的柔光擴散（bloom），讓整片藍光暈開。
- **圓心大八卦用真實透視逐件繪製**：不是貼一張平面圖，所以不管往下看多少度，外環都和扇區內緣無縫銜接。
- **字體**：盤面發光字使用「霞鶩文楷 TC」楷體（SIL OFL 授權，只裁出用到的約 570 字、約 170 KB，離線可用；缺字時退回宋體）。重新產生字型：下載 `LXGWWenKaiTC-Medium.ttf` 後執行 `KAI_TTF=<路徑> npm run kai`。授權說明見 `src/assets/fonts/KAI-LICENSE.md`。整個 App 預先快取約 0.6 MB，沒有任何 AI 模型要下載。
- **姿態正確性有測試**：3D 公式與原版的方位引擎，在 100 多組手機姿態下交叉比對，結果一致。
- **盤面與顯示的度數一致**：水平朝向以感測引擎的輸出（含校正、磁偏角）為準。
- **特效會自動降級**：掃描光束、擴散波紋、流光、光塵只是裝飾。畫面幀率不足時依序關閉（完整→精簡→靜態），系統開啟「減少動態效果」時固定為靜態，不影響方位資訊。
- **文字圈內容只放真實羅盤資料**：卦名、五行與洛書數、八星與星意、十二地支、二十四山、二十四節氣有單元測試驗證角度（子在北、艮 45°、乾 315°、冬至在北、立春在艮等），不放奇門術語。二十四節氣圈是羅盤的傳統圖案，僅作節氣意象。
