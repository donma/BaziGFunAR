## 2. 待實機量測（阻斷性）

| 項目 | 檢核要求 |
|---|---|
| 相機與盤面幀率 | 以 30 FPS 為目標，記錄中位數與低幀情況（Canvas 每幀約數百次投影＋發光疊色） |
| 方位準確度 | 已知方位（北／東／南／西）比對 HUD 與盤面；記錄 iOS `webkitCompassHeading` 與 Android `deviceorientationabsolute` 的偏差 |
| 盤面穩定度 | 慢轉、輕晃、快速甩動時盤面不嚴重抖動、無錯位 |
| 透視手感 | 預設視角 66° 是否合理；各機型是否需要在設定微調 |
| 校正流程 | 校正後盤面立即對齊；金屬／電器旁偏移的實際表現 |
| 長時間使用 | 連續 10 分鐘：相機、發熱、耗電、記憶體 |
| 雙平台授權 | iPhone Safari／Android Chrome 授權、拒絕、重新啟動、切背景、直橫旋轉 |
| 拍照合成 | iOS 字體首次繪製、盤面與暗角是否與畫面一致 |
| 離線 | 開啟過一次後關網路仍可使用 |

## 3. 建議實機測試矩陣（代表性，非支援承諾）

| 平台 | 機型範例 | 瀏覽器 | 優先測項 |
|---|---|---|---|
| iOS | iPhone 14／SE | Safari、加入主畫面 | `requestPermission` 手勢、指南針、合成照字體、離線 |
| Android | Pixel 7／中階機 | Chrome | `deviceorientationabsolute`、幀率、發熱 |
| 橫式 | 上述機型橫向 | 同上 | HUD 不遮盤面、快門可達、safe area |

## 4. 已知限制（不可隱瞞）

1. 完全依賴手機磁力計，室內干擾會偏；尚無實機精度數據，不承諾百分比。
2. 地板是假設離地 1.4 公尺的虛擬平面，不追蹤位移，不貼合真實地板；視角為概估值。
3. 直式手機水平視角小於一個扇區，一次大約只看到一個扇區。
4. 盤面是朝向參考；住宅中心需使用者確認，不等於整戶住宅正式判定。
5. 真北需使用者輸入磁偏角。
6. 無舊版人物匯入；無物件／門窗辨識；無雲端與帳號。

## 5. 完成定義對照

程式碼、建置、測試、桌面端到端驗證、文件與限制清單已完成。**主流手機實機量測尚未完成**，在實機通過前，本專案不自認滿足完整完成定義。
