## 4. 已知限制（不可隱瞞）

1. 純 PWA 無原生 ARKit 等級空間錨定；貼紙是 2D 畫面吸附，不是房間固定。
2. COCO-SSD 不支援門／窗／牆面／地板；門窗以幾何候選＋人機確認，牆面地板第一版不呈現。
3. 畫面角位移使用概估水平視角 62°；住宅宮位標記為選用，需使用者確認站於住宅中心，不是自動室內定位。
4. 模型首次約 18.6 MB；首次載入時間、推論耗時與耗電未實機量測。
5. iOS Safari 照片合成的字體首次繪製差異需在實機確認（原版也有相同風險）。
6. 真北需使用者輸入磁偏角；內建磁偏角資料不可得，故不提供自動真北。
7. 無舊版人物匯入（決策 29A）；人物資料需在新專案重新建立。
8. 不提供地板吉凶色塊、九宮扇區投影、粒子／呼吸光效、雲端 AI、帳號登入。

## 5. 完成定義對照

規格第 16 節「完成定義」要求：已驗證主流手機上實際使用相機、對物件顯示穩定 Sticker、清楚區分朝向參考／住宅宮位、完成本機拍照與匯出、不遺漏原版核心功能。

**本機可交付部分**：程式碼、建置、測試、桌面端到端驗證、文件與限制清單全部完成。
**尚未達成部分**：主流手機實機量測與驗收（第 2 節所有待實機欄位）。在實機通過前，本專案**自認尚未滿足完整完成定義**；此處如實標註，不以示意圖冒充實機成果。
