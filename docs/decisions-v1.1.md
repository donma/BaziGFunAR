# 決策變更記錄（v1.1：偽 VR 八宅盤）

日期：2026-11-27。依使用者新需求推翻部分規格書 v1.0 的決策。規格書原檔（`bazigfun-ar-spec-v1.0.md`）保留不改，以本檔為準。

## 使用者決定

1. 換掉門窗辨識方式（幾何候選雜訊過多）。
2. **拿掉所有 AI 物件判斷**。
3. 拿掉方位卡片，改成「站在羅盤中央，地板上顯示八宅資訊」。
4. 追求好看、有驚豔感：偽 VR。

經逐項確認：保留實景相機並調色；盤面為地板八方位盤加水平線方位標記；點扇區開底部資訊卡；轉動順滑加微光、不做持續動畫。

## 保持不變的原則

- 計算正確與真實性優先：吉凶只由人物命卦＋方位規則計算；原版核心逐字移植並以測試驗證。
- 不宣稱未驗證能力：地板是虛擬平面，不是偵測；住宅中心需使用者確認；不承諾實機精度。
- 隱私與離線：全程本機，不上傳影像或個資。

## 視覺升級（v1.1.1）：青藍霓虹

參考圖是電影中的發光羅盤地板（鳥瞰、青藍霓虹字）。使用者要求視角維持**第一人稱**（站在盤上往外看），只借用配色、字體質感與文字密度，並要求「一切要炫泡」。

| 項目 | 決定 |
|---|---|
| 配色 | 青藍霓虹＋白熱字芯；實景調成冷暗藍 |
| 吉凶區分 | 藍色為主：吉＝亮青、凶＝靛藍並帶一點暖色邊光；另有「吉／凶」字（取代規格 8 的綠／紅） |
| 文字圈 | 約 4 圈：卦名、八星名（含方位與吉凶）、十二地支、二十四山；只放真實羅盤資料，不放奇門術語 |
| 字體 | 維持宋體（發光貼圖）；不採毛筆字體 |
| 特效 | 放寬原「不做持續動畫」：加入掃描光束、擴散波紋、流光、光塵與開場逐圈點亮。裝飾性質，不影響方位語意；幀率不足自動降級，系統「減少動態效果」時固定靜態 |
| 介面配色 | 底部卡、人物／設定／命卦面板、首次引導一併改為深藍玻璃風；拍照資訊卡同步 |

注意：特效會增加耗電與發熱，需實機評估。

## 視覺再升級（v1.1.2）：貼近參考圖的寶藍霓虹

使用者再次提供參考圖，要求「盡量接近這種風格與感覺」，並指出圓心的八卦要大、要藍色光暈。

| 項目 | 決定 |
|---|---|
| 配色 | 由青綠改為飽和寶藍（吉＝亮藍、凶＝靛紫＋暖橘邊光）；實景調成深藍並加地面藍光霧 |
| 字體 | **推翻先前「維持宋體」**：改用楷體（霞鶩文楷 TC，OFL，裁切內嵌），描邊加粗接近毛筆感；缺字退回宋體 |
| 文字密度 | 增至約 8 圈：卦名、五行洛書、方位吉凶、星名、星意、十二地支、二十四山、二十四節氣；圓心大八卦內再加卦名圈與二十四山圈 |
| 結構 | 多層八角形與 {8/3} 星形切面線、同心光環 |
| 圓心 | 填滿正下方圓心的大八卦（太極＋八卦環＋小字圈），每個元件用真實透視繪製 |
| 光暈 | 縮小放大式柔光擴散（bloom）＋字貼圖加寬光暈；拍照合成照同樣處理 |
| 朝下看 | 修正：朝下看圓心時感測引擎標「朝向不穩」，盤面不再因此調暗 |

誠實備註：二十四節氣圈依太陽黃經排列（冬至在北），為羅盤傳統圖案，僅作意象；字體為通用楷書，並非真正毛筆書法；效果在真機的耗電與幀率待測。
